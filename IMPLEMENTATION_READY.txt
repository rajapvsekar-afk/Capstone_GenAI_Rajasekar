📋 AGENT FRAMEWORK

Agent 1: Document Verification (15% weight)
├─ Checks completeness, consistency, anomalies
└─ Scores 0-100 based on documentation quality

Agent 2: Credit Analysis (30% weight)
├─ Credit score (40%), history (15%), payment (20%)
├─ Bankruptcy (15%), utilization (10%)
└─ Weighted composite scoring

Agent 3: Financial Risk (30% weight)
├─ DTI ratio (25%), LTV ratio (20%)
├─ Employment (20%), income (20%), assets (15%)
└─ Risk-weighted financial metrics

Agent 4: Compliance (25% weight)
├─ Age (21-65), tenure (<70 maturity)
├─ KYC, AML, loan limits
└─ Pass/fail regulatory checks

Final Score = (Doc×0.15) + (Credit×0.30) + (Risk×0.30) + (Compliance×0.25)

Thresholds:
  ✓ ≥70 = APPROVED
  ⚠ 45-70 = MANUAL REVIEW
  ✗ <45 = REJECTED

1. Presentation (Streamlit)
   └─ Loan form, status dashboard, decision display

2. API Gateway (FastAPI)
   └─ Validation, rate limiting, security

3. Orchestration (LangGraph)
   └─ Parallel coordination, state management

4. Agents (4 parallel FastAPI services)
   ├─ Document Agent
   ├─ Credit Agent
   ├─ Risk Agent
   └─ Compliance Agent

5. Data Layer
   ├─ PostgreSQL (persistent)
   ├─ Redis (cache)
   └─ MCP Servers (external data)
